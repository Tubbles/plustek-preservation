# Documentation index

- `research.md`: what is known about the OpticFilm 120 from public sources (controller, software support history, related scanners, failure modes).
- `hardware/usb.md`: USB identity and behaviour of the owner's unit.
- `manual/quick-guide.md`: transcription of the printed Quick Guide (buttons, LEDs, holders, installation).
- `log/`: dated decision logs, one file per day, tagged for grepping.
- `work/`: work items. Each file has a `Status:` line (`todo`, `in progress`, `blocked`, `implemented`, `done`).
